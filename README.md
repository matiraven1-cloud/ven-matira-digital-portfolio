# Ven Kurbie V. Matira — Portfolio Website

## Files
- `index.html` — website content
- `style.css` — layout, colors, responsive design
- `script.js` — mobile navigation and current year
- `a12d1949-5641-44bd-936f-5b7aa0905ea1.jpg` — profile photo
- `court-photo.png` — Court Reserve project background image

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example, `ven-matira-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, `a12d1949-5641-44bd-936f-5b7aa0905ea1.jpg`, and `court-photo.png` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Personalize before publishing
- Replace the `YOUR PHOTO` placeholder in `index.html` with your own image.
- Confirm whether the database skill is MySQL and add verified programming languages/tools.
- Add any additional project details, certificates, and professional links.
- Review the contact information before making the site public. This version displays the email address but does not publish the phone number.
- Age is not displayed; it is generally unnecessary on a public student portfolio.
